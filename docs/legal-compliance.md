# Правовая проверка концепции «ОМА Дом» по законодательству Республики Беларусь

> **Важно.** Это рабочий разбор для хакатона, а не юридическое заключение. Перед
> запуском каждого модуля редакции актов нужно сверить на Национальном
> правовом интернет-портале (pravo.by) или в ИПС «ЭТАЛОН» и получить заключение
> юриста. Законодательство РБ часто меняется, поэтому здесь указаны акты
> целиком, без номеров статей: конкретные статьи нужно смотреть в актуальной редакции.

## 2. Разбор по модулям

### 2.1. Проекты и сметы
- Смета — **информационный расчёт**, а не проектная документация. Явно писать:
  «Расчёт ориентировочный, не является проектом».
- Работы, затрагивающие несущие конструкции, инженерные сети, газ, вентиляцию,
  санузлы над жилыми комнатами, — **переустройство/перепланировка**. По
  Жилищному кодексу нужно решение исполкома. Сервис показывает предупреждение и
  ссылку на процедуру, **не предлагает делать это без разрешения**.
- Газовое оборудование и электроустановки — только организации/специалисты
  с соответствующими допусками; такие услуги в маркетплейсе помечаются отдельно.

### 2.2. Маркетплейс услуг
- **Кто сторона договора.** Выбираем модель, где договор подряда/оказания услуг
  заключает исполнитель, а ОМА — посредник (агент/информационный посредник)
  по договору с исполнителем. Это записывается в публичной оферте для клиента
  и в договоре с партнёром.
- **Информация потребителю** (Закон о защите прав потребителей): наименование
  исполнителя, УНП, адрес, цена, сроки, гарантия, порядок претензий — до оплаты.
- **Статус исполнителей.** Физлицо без регистрации допускается только в пределах
  видов деятельности, разрешённых для ремесленников / плательщиков налога на
  профессиональный доход. Иначе — ИП или юрлицо. Сервис проверяет статус при
  подключении и раз в период.
- **Незаконная предпринимательская деятельность.** Платформа не должна
  систематически подключать «серых» исполнителей — иначе риск для ОМА как
  соучастника схемы.
- **Отзывы и рейтинг:** только по подтверждённым заказам, без удаления
  негатива за плату; правила ранжирования публикуются (честная конкуренция,
  достоверность рекламы).

### 2.3. Оплата и единая корзина
- Деньги клиента за услугу партнёра: банковский эквайринг с расщеплением
  платежа либо агентская схема, проверенная юристом и банком на соответствие
  Закону о платёжных системах. **Не накапливать деньги партнёров на счёте ОМА
  без правового основания.**
- Чек/документ об оплате на каждую позицию: товар — от ОМА, услуга —
  от исполнителя (или агентский чек в допустимой схеме).
- Поэтапная оплата = предоплата за этап; если этап не принят, возврат по
  правилам Закона о защите прав потребителей.
- Рассрочка и кредит — **предоставляет банк**; ОМА показывает условия банка
  без искажения (полная стоимость, ставка).

### 2.4. Паспорт дома и данные клиента
- Основание обработки: исполнение договора (история заказов, гарантии) и
  **отдельное согласие** на маркетинг и аналитику.
- Согласие — свободное, однозначное, информированное; отдельная галочка, не
  «предзаполненная»; простой отзыв согласия в профиле.
- Политика в отношении обработки персональных данных опубликована; назначено
  лицо, ответственное за обработку; ведётся перечень обработок.
- Передача данных исполнителю — только то, что нужно для заказа (имя, телефон,
  адрес объекта), на основании договора; с партнёром заключается соглашение о
  поручении обработки.
- Фото помещений могут содержать лишние персональные данные — предупреждать
  и не использовать их для обучения моделей без согласия.
- Хранение — на серверах в РБ (Указ № 60, требования ОАЦ); трансграничная
  передача — только в допустимые страны/с разрешения в установленных случаях.
- Cookies и трекинг — по согласию (позиция НЦЗПД), кроме технически необходимых.
- Инцидент (утечка) — уведомление НЦЗПД в установленный срок.

### 2.5. Коммуникации и маркетинг
- Сервисные уведомления (статус заказа, гарантия, обслуживание по
  подписке) — отдельно от рекламы.
- Рекламные push/SMS/e-mail — **только по предварительному согласию**
  (Закон «О рекламе»), с отпиской в один клик.
- Акции с призами по жребию — рекламная игра: правила, порядок
  регистрации/уведомления — по законодательству о рекламных играх.

### 2.6. Партнёрские вертикали
- **Страхование:** ОМА — страховой агент по договору со страховой
  организацией; договор страхования заключает страховщик.
- **Недвижимость:** ОМА не оказывает риэлтерские услуги. Только подготовка
  объекта (ремонт, клининг, хоум-стейджинг) и, при желании, переход на сайт
  риэлтерской организации из реестра.
- **Отходы:** вывоз строительного мусора — организации, имеющие право на
  обращение с отходами, с документами о передаче.
- **Энергоэффективность:** расчёт экономии — ориентировочный, без гарантий
  «экономии X%», если они не подтверждены (достоверность рекламы).

### 2.7. Лояльность
- Правила программы — публичная оферта; порядок начисления/списания баллов,
  срок действия, правила изменения.
- Баллы — не электронные деньги и не средство платежа вне программы.

## 3. Чек-лист перед запуском

- [ ] Выбрана и согласована с юристом и банком модель расчётов за услуги партнёров
- [ ] Публичная оферта для клиентов (товары и посредничество по услугам)
- [ ] Договор с исполнителями (агентский/посреднический, гарантия, ответственность,
      соглашение о поручении обработки ПД)
- [ ] Включение интернет-магазина/площадки в Торговый реестр, информация на сайте
      по Правилам торговли по образцам
- [ ] Политика обработки ПД, формы согласий, ответственное лицо, перечень обработок
- [ ] Классификация ИС и система защиты информации по требованиям ОАЦ, хостинг в РБ
- [ ] Процедура проверки статуса исполнителей
- [ ] Предупреждения о переустройстве/перепланировке в сценариях ремонта
- [ ] Разделение сервисных и рекламных сообщений, учёт согласий на рекламу
- [ ] Договоры с банками (рассрочка, кредит) и страховыми организациями (агент)
- [ ] Порядок претензий и возвратов для товаров и для услуг
- [ ] Вся клиентская информация на русском и/или белорусском языке
