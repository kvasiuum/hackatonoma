# ОМА Дом

Концепция сервиса для Space Hackathon with OMA: ОМА ведёт ремонт санузла от 3D-проекта
до гарантии — материалы, мастер, контроль и обслуживание в одном окне и под одной
ответственностью, а **Паспорт дома** возвращает клиента в ОМА на каждом следующем поводе.

- **Прототип:** https://kvasiuum.github.io/hackatonoma/
- **Презентация:** https://kvasiuum.github.io/hackatonoma/slides/ (PDF — [`slides/oma-dom.pdf`](slides/oma-dom.pdf))

## Коротко

| | |
|---|---|
| Направление | Сопровождение ремонта «под ключ» и жизни дома после него. Пилот — санузел |
| Клиент | «Первый серьёзный ремонт»: капитальный ремонт санузла · комфорт · новичок · омниканальность |
| Проблема | На этапах смета → мастер → работы → приёмка → постсервис клиент остаётся один; магазин помогает купить, но не помогает сделать |
| Точка входа | Бесплатный 3D-проект ванной ОМА, карточка товара «с установкой», QR на чеке |
| Ключевые функции | Смета с пояснениями, резерв одной партии, доставка к этапу, работы с фиксированной ценой, приёмка по этапам, Паспорт дома, «Баланс» за весь проект |
| Почему ОМА | Один ответственный за товар и работу; 70 000+ SKU в наличии; бригады уже покупают в OMA PRO; 800 000+ участников «Баланс» |
| Деньги | Дополнительная маржа товаров + 20% маржи на работах; вклад ≈ 446 BYN на проект; безубыточность ≈ 90 проектов в месяц |
| Право | Пилот в модели «ОМА — исполнитель работ», учтены изменения 2024–2026 годов |

## Прототип

[`index.html`](index.html) — один файл без сборки, открывается в браузере. Анимации на
Motion подгружаются с CDN; без сети прототип работает без анимаций. Компании, УНП,
адреса и цены в прототипе условные, оплата не проводится.

## Статус
